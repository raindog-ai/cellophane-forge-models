# HTDemucs ONNX — Portable Audio Separation

A static ONNX export of base HTDemucs for audio separation projects, including personal use and aural research. Designed for efficient inference and portability with a compatible host runtime; no universal compatibility or benchmark speedup is claimed.

**[Read the model card](MODEL-CARD.md)** for the runtime contract, verified artifact identity, conversion provenance, intended use, and qualification limits.

- [Download and release files](https://github.com/raindog-ai/cellophane-forge-models/releases/tag/htdemucs-onnx-v1)
- [MIT license and upstream attribution](LICENSE.demucs)

The model produces drums, bass, other instruments, and vocals through the matching audio DSP and inference integration. It is not a standalone audio-file application or hosted processing service. No training audio is distributed here. Personal-use intent does not replace or narrow the upstream MIT license.
